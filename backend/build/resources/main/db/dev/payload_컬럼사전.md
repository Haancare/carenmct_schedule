# payload 컬럼 사전 (탭별)

작성일 2026-07-17. 근거: `gongdan_archive.raw_data` 180,278행 전수 조회.

`raw_data.payload`(jsonb) 안의 컬럼을 탭별로 설명한다. **탭이 다르면 payload 구조가 완전히 다르다.**

---

## 0. 먼저 알아야 할 것

### 0.1 탭 간 payload는 공유되지 않는다

전체 고유 컬럼 **190개** 중 **162개(85%)가 한 탭 전용**이다. 2개 이상 탭에 걸친 건 28개뿐.

| 걸친 탭 수 | 컬럼 |
|---|---|
| **7개** | `LTC_MGMT_NO` — 유일하게 거의 모든 탭에 있음 (carer 제외) |
| **6개** | `PRS_NM` |
| **4개** | `CHE_NM` |
| 3개 | `CHE_BDAY`, `CLFY_CD`, `LTCP_CLSFC_CD`, `LTCP_MECH_CD`, `LTCP_MECH_NM`, `LTCP_OFFR_DT`, `LTCP_OFFR_YYYYMM` |
| 2개 | 18개 |

**payload를 읽기 전에 반드시 `tab` 값으로 분기해야 한다.** 공통으로 믿을 수 있는 건 `LTC_MGMT_NO` 하나뿐이다.

### 0.2 값이 없는 것과 항목이 없는 것은 다르다

항목(키)은 탭마다 항상 고정이다. 공단이 그 칸을 안 채우면 **빈 문자열 `""`** 로 들어온다. RFID는 예외적으로 `"-"` 를 쓴다.

### 0.3 모든 값이 문자열이다

숫자도 `"105120"`, 날짜도 `"20260101"`, 시간도 `"0805"` 처럼 문자열이다. 계산·정렬하려면 변환해야 한다.

### 0.4 ⚠️ 보고서 최대 함정 — `BILL_*` 은 수급자 금액이 아니다

명세서의 `BILL_ASB_DMD_TOT_AMT`(청구액)는 **그 청구서 전체(수급자 수십 명 합계)** 다. 명세서 한 장의 금액이 아니다.

실측: `140A / 2026-06 / 청구번호 2026060002` — 명세서 **73장이 전부 같은 `BILL` 값(76,905,960원)** 을 갖는다. 수급자별 합계(`DTST_ASB_DMD_TOT_AMT` 합)는 76,639,190원.

→ **수급자별 금액은 `DTST_*` 를 쓴다. `BILL_*` 를 쓰면 73배 부풀려진다.**
(`BILL == DTST` 인 행이 1,358중 11건 있는데, 명세서가 1장뿐인 청구서라서 우연히 같은 것이다.)

### 0.5 수가명 접두어 3종

같은 수가코드에 이름이 여러 개인 원인이 밝혀졌다. 접두어가 붙는다.

| 접두어 | 건수 | 뜻 |
|---|---|---|
| `(인지)` | 8,929 | 인지활동형 급여 |
| `(분할)` | 1,654 | 분할 제공 |
| `(미이용수가)` | 276 | 미이용 처리 |

→ 수가코드를 사전화할 때 이름만 보면 안 되고, 접두어를 별도 플래그로 분리해야 한다.
